# Textures

This directory contains optional Mod Menu textures.

- `mod_menu_no_image.png` is used when a mod registered Mod Menu settings but did not provide an icon.
- Additional PNG assets should keep globally unique names, preferably prefixed with `mod_menu_`.

`THIRD_PARTY.md`.
